ADDENDUM PROMPT — "Beyond the Headline" (adds to existing style system)

Keep all previously established STYLE RULES, palette, typography, and pixel-art 
constraints (no emoji, no flat icons, dithered shading, hard pixel edges, chunky 
2-4 frame animation). This prompt extends three areas: the Community Map environment, 
a living landing screen, and a new game mode.

1. COMMUNITY MAP — ENVIRONMENTAL DETAIL PASS

Expand Screen 4 (Community Map) into a fuller small-town pixel environment, not just 
isolated buildings on a blank background:
- Add a network of pixel dirt/cobblestone roads connecting every building, with subtle 
  tire-track or footpath dithering worn into well-traveled routes
- Add environmental filler between buildings: pixel trees (2-3 varieties, hand-shaded, 
  slightly different heights for depth), hedges, lampposts (lit with a small 2-frame 
  flicker), park benches, a fountain or town square as a central landmark
- Add residential houses as background/atmosphere structures (not clickable levels) 
  to make the town feel lived-in — vary rooftops and window lighting (some lit yellow, 
  some dark) so the town reads as inhabited, not staged
- Include small ambient details: a parked pixel bicycle, a mailbox, a bus stop bench, 
  birds on a wire — these should NOT be interactive, just texture
- Keep the level-node buildings (bakery, city hall, market, newspaper office, police 
  station, school) visually distinct from the background houses — larger, with their 
  case-tag pin and a slightly more saturated/detailed treatment so they read as 
  "clickable" at a glance
- Light isometric or 3/4 top-down angle, consistent single light source (e.g. a 
  low evening sun) casting hard pixel shadows the same direction across every object
- Consider a subtle parallax-ready layering note: distant background (hills/sky), 
  midground (roads, trees, houses), foreground (level-node buildings) — even as a 
  static mockup, indicate which layer each element belongs to

2. LANDING SCREEN — LIVING INVESTIGATION SCENE

Replace the static desk illustration on Screen 2 (Landing/Title) with an animated 
establishing scene, described as a frame sequence:
- Wide pixel street or newsroom-exterior scene at dusk, matching the town's palette
- 2-3 small pixel NPC characters walking on a slow, looping cycle (4-6 frame walk 
  cycle each) — e.g. a citizen crossing the street, a paperboy delivering to a stoop, 
  a figure pausing to read a posted notice on a board
- One subtle "hook" animation detail: a pixel newspaper page blowing across the street, 
  or a single window light flicking on, to draw the eye without being busy
- Layer the game logo and the three main buttons ("Continue Case," "New Investigation," 
  "Settings") over this scene on a semi-opaque dithered panel so they stay legible 
  against the moving background
- Describe this as a looping ambient animation (not a one-time intro) — the scene should 
  feel alive behind the menu, low-motion and atmospheric rather than a flashy cutscene
- Optional: a short 3-4 frame "camera pan" from a wide town shot into the desk/menu 
  view on first load only, before settling into the looping ambient state

3. NEW GAME MODE — "Beat the Clock" (Time Attack)

Add a second mode alongside the main story-driven Community Map:
- Accessible from the Landing screen as a fourth button, "Beat the Clock," styled

- Verdict screen (Screen 6 equivalent) adds a time-bonus Tips calculation and a 
  "Best Time" pixel leaderboard card comparing the current run to the player's 
  personal best
- Visually flag this mode's UI accents in a slightly different accent tone (e.g. 
  swap brass highlights for the muted red) so players always know which mode they're 
  in at a glance
